## Технические характеристики

### Компоненты
- **StatsHeader** — заголовок раздела
- **FilterPanel** — горизонтальная панель с дропдаунами для фильтров
- **ResultsBlock** — 3 карточки с основными метриками
- **EngagementBlock** — 2×2 сетка метрик вовлечённости  
- **SpeedCoverageBlock** — 3 карточки скорости и покрытия
- **TrendsBlock** — 2 графика на Recharts
- **SourcesBlock** — таблица источников
- **TeamBlock** — таблица команды с интерактивной сортировкой
- **InsightsBlock** — пустой стейт с TODO

### Progressive Rendering
- Каждый блок загружается независимо с собственным skeleton
- Фильтры триггерят рефетч API без перезагрузки страницы
- Блокирующих loader'ов на весь экран нет

### Фильтры
- **Период:** День, Неделя, Месяц, Свой (с date picker)
- **Исходы:** Все / Цель достигнута / Закрыт без исхода / Без ответа / Открыт
- **Каналы:** Загружаются динамически из channels.type организации
- **Кампании:** Загружаются динамически из distinct(leads.campaign)
- **Дата-диапазон:** Текстовый дисплей "ДД.МММ – ДД.МММ.ГГГГ"

### Метрики
- N/A показывается вместо 0%, когда знаменатель = 0 или данных нет
- Стрелки тренда (↑ зелёная / ↓ красная) для изменения vs прошлый период
- Время форматируется как "2м 34с" или "34с"

### API
- Вызывает `GET /api/stats?period=...&from=...&to=...&agent_id=...&channel=...&campaign=...&outcome=...`
- Использует SECURITY INVOKER RPC функцию `fn_get_stats()` в Postgres
- Требует аутентификации + проверка org_members

## Файлы

- `/app/api/stats/route.ts` — API эндпоинт (создан на предыдущем шаге)
