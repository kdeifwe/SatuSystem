### 3. Тесты с моком системного времени и изоляция

**Проблема:** В полном прогоне тестов flaky-падения могут возникать, если тест подменяет глобальное время (`Date.now`) и не восстанавливает его в `finally`/`afterEach`. Даже если отдельный запуск проходит, соседние тесты могут видеть уже замоканное время и падать или вести себя не так, как ожидается.

**Текущее состояние:**
- ⚠️ В [tests/smart-broadcasts.test.ts](tests/smart-broadcasts.test.ts) есть сценарий с подменой `Date.now` для edge-case work-hours; он теперь защищён `try/finally`, но этот класс проблем остаётся важным для будущих тестов.

**Требуется:**
- [ ] Для всех тестов, которые мокают системное время, использовать `try/finally` или `afterEach`, чтобы гарантированно восстанавливать реальное время после каждого теста.
- [ ] Не допускать мутаций глобального `Date`/`Date.now` без явного cleanup в рамках одного теста.
