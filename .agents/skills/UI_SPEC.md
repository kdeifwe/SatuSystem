# UI-SPEC: Дашборд и База знаний — детальная спецификация компонентов

Это дополнение к `/docs/SPEC.md`. Положи этот файл рядом, как `/docs/UI_SPEC.md`.
Референс — скриншоты конкурента (Pleep), но бренд везде — **Satu.AI**, основной акцентный
цвет — **#1557FF** (электрик-блю), а не цвет конкурента. Никаких логотипов/названий Pleep
в коде, текстах или комментариях быть не должно — берём только структуру и паттерны
взаимодействия.

Дизайн-токены ниже — отправная точка. Если в проекте уже подключён shadcn/ui или другая
система — используй её примитивы (Button, Badge, Input, Tabs, Card), не изобретай заново.

## 1. Страница `/dashboard` — список агентов

### 1.1 Верхняя навигация (header), высота ~64px, border-bottom 1px gray-200

Слева направо:
1. Логотип Satu.AI + название (клик → `/dashboard`)
2. Ссылки навигации: `Дашборд`, `Команда`, `Настройки` — текст gray-600, активная страница — text-gray-900 font-medium. **Без** "Стоимость" / "Обновления" / "Туториалы" — это маркетинговые ссылки конкурента, у нас внутренний инструмент, их не делаем.
3. Справа: круглый аватар пользователя (инициал имени, фон #1557FF, белая буква) — клик открывает dropdown: `Профиль`, `Настройки`, `Выйти`.

### 1.2 Заголовок страницы

```
<h1 class="text-2xl font-bold text-gray-900">Дашборд</h1>
<p class="text-sm text-gray-500 mt-1">Управляйте ИИ-агентами в одном месте</p>
```

Справа от заголовка (flex justify-between, та же строка):
- Кнопка **"Создать ИИ-агента +"** — solid, фон #1557FF, белый текст, rounded-lg, иконка `Plus` справа от текста. Hover — #0E3FC9. Это единственная кнопка справа — кнопку "Купить подписку" НЕ делаем (модуль подписок исключён по SPEC.md раздел 0).

### 1.3 Сетка карточек агентов

`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`, отступ сверху от заголовка 32px.

Каждая карточка — `<AgentCard />`:

```
┌─────────────────────────────────────┐
│ [превью-блок, h-40, rounded-t-xl]    │  ← см. 1.3.1
├─────────────────────────────────────┤
│ Название агента (font-semibold)  ⋯  │  ← кебаб-меню справа
│ Краткое описание (text-gray-500,    │
│ text-sm, line-clamp-2)              │
└─────────────────────────────────────┘
```

Карточка: `border border-gray-200 rounded-xl overflow-hidden hover:shadow-md transition-shadow cursor-pointer`. Клик по карточке (кроме кебаб-меню) → переход на `/dashboard/[agentId]`.

**1.3.1 Превью-блок** — это НЕ скриншот реального чата, а статичный декоративный блок:
- Фон: `bg-gradient-to-br from-[#1557FF] to-[#3B7BFF]` (или нейтральный `bg-gray-50` для агентов без активности)
- В левом верхнем углу — маленький "чип": белый кружок с первой буквой имени агента + название агента рядом, на полупрозрачной белой подложке (`bg-white/90 rounded-full px-3 py-1.5 flex items-center gap-2`)
- Остальное пространство — просто декоративные серые скелетон-полоски (`bg-white/30 rounded h-3`), 2-3 штуки разной ширины, имитируют превью переписки. Без анимации pulse — это не реальный лоадер, а статичный декор.

**1.3.2 Кебаб-меню** (иконка `MoreHorizontal`, в кружке `bg-white border border-gray-200`, top-right поверх превью или под названием — как на референсе, под названием справа): при клике — dropdown с пунктами `Редактировать`, `Дублировать`, `Удалить` (удаление — с подтверждением через модалку, текст "Удалить агента «{name}»? Это действие необратимо.").

### 1.4 Пустое состояние

Если у организации 0 агентов — вместо сетки показать центрированный блок:
- Иконка (например `Bot`, 48px, gray-300)
- Текст "У вас пока нет ни одного ИИ-агента"
- Кнопка "Создать первого агента +"

### 1.5 Футер

Минимальный, не маркетинговый (это внутренний инструмент, юр. блоки конкурента не копируем):
```
<footer class="border-t border-gray-200 mt-16 py-6 text-center text-sm text-gray-400">
  © {год} Satu.AI — внутренняя платформа
</footer>
```

## 2. Layout агента `/dashboard/[agentId]/*` — sidebar-оболочка

Двухколоночный layout: фиксированный sidebar слева (`w-64`, border-right gray-200, белый фон, `flex flex-col h-screen sticky top-0`), справа — контент страницы со скроллом, padding `p-8`.

### 2.1 Структура sidebar (сверху вниз)

**Шапка sidebar:**
- Логотип Satu.AI + кнопка сворачивания sidebar (иконка `PanelLeftClose`)

**Группа "Основные"** (заголовок группы — `text-xs uppercase text-gray-400 font-medium px-3 py-2`, с шевроном для сворачивания группы):
- `Диалоги` — иконка `MessageSquare`
- `База знаний` — иконка `BookOpen`
- `Тестирование` (Sandbox) — иконка `FlaskConical`
- `Улучшение` — иконка `Sparkles`
- `Рассылки` — иконка `Send`
- `Сценарии` — иконка `Workflow`
- `Настройки` — иконка `Settings`

**Группа "Аналитика":**
- `Статистика` — иконка `BarChart3`

**Группа "Интеграции":**
- `Интеграции` — иконка `Plug`
- `Расширения` — иконка `Puzzle`
- `Инструменты` — иконка `Wrench`
- `Голосовой агент` — иконка `Mic`

**Группа "Команда":** (есть в SPEC.md раздел 6.12, на референсе её нет, но у нас она нужна)

Каждый пункт: `flex items-center gap-3 px-3 py-2 rounded-lg text-sm text-gray-600 hover:bg-gray-50`. Активный пункт: `bg-[#EEF2FF] text-[#1557FF] font-medium`, иконка тоже в цвете акцента.

**ВАЖНО:** на референсе есть блок "До конца пробного периода..." + "Купить подписку" — **этого не делаем**, подписок и пробных периодов в продукте нет (SPEC.md раздел 0). На этом месте в sidebar **ничего не добавляем**, просто группы идут до низа.

**Низ sidebar (sticky bottom):**
- Разделитель (border-top)
- Ссылка `Помощь` — иконка `HelpCircle`
- Блок пользователя: круглый аватар-инициал + имя пользователя + меню из трёх точек справа (`Профиль`, `Сменить организацию` если когда-то будет мультитенант, `Выйти`)

## 3. Страница `/dashboard/[agentId]/knowledge` — База знаний

### 3.1 Заголовок

```
<h1 class="text-2xl font-bold text-gray-900">База знаний</h1>
<p class="text-sm text-gray-500 mt-1">
  Загружайте документы и другие материалы, которые ИИ-агент будет использовать
  для ответов вашим клиентам
</p>
```

### 3.2 Блок "Документы"

Карточка (`border border-gray-200 rounded-xl p-6`):

- Заголовок `Документы` (font-semibold), подзаголовок gray-500 text-sm: "Загружайте документы, содержащие информацию о вашем бизнесе: цены, виды услуг, товары, контакты и т.д."
- Кнопка `Загрузить ещё +` — outline (`border border-gray-300 rounded-lg px-4 py-2 text-sm font-medium hover:bg-gray-50`), открывает модалку выбора источника: `Файл (PDF/DOC/DOCX/TXT)`, `Сайт (краулер)`, `Google Docs`, `Google Sheets`, `Instagram` — согласно SPEC.md `kb_sources.type`.
- Ниже — список загруженных источников, каждый строкой:
  ```
  [иконка типа источника]  Источник: <title>     [бейдж "N элементов"]   [⬇ скачать] [🗑 удалить]
  ```
  Строка: `flex items-center justify-between py-3 border-b border-gray-100 last:border-0`. Бейдж count: `bg-gray-100 text-gray-600 text-xs rounded-full px-2.5 py-1`. Иконки справа — `text-gray-400 hover:text-gray-700`, без подписи, с `title=` атрибутом для тултипа.
  - Статус источника (`kb_sources.status`): если `pending`/`processing` — показывать вместо бейджа count маленький спиннер + текст "Обрабатывается...". Если `error` — красный текст "Ошибка обработки" + иконка retry.

### 3.3 Блок "Продукты, вопросы, процедуры, контакты и др."

Карточка (`border border-gray-200 rounded-xl p-6`):

**Заголовок строкой:**
```
<h2>Продукты, вопросы, процедуры, контакты и др. <span class="text-gray-400">({count})</span></h2>
[ⓘ инфо-тултип: "Это структурированные элементы базы знаний — каждый используется
   как отдельный, более точный источник ответа, в отличие от чанков из документов"]
                                            [+ Добавить]  ← кнопка справа, solid #1557FF
```

При клике "+ Добавить" — модалка с выбором типа элемента: `Q&A пара` (вопрос+ответ), `Продукт/услуга` (название, цена, описание), `Процедура` (название, шаги), `Контакт` (имя, телефон/email/соцсеть), `Другое` (свободный текст). Соответствует `kb_sources.type = 'manual'` или `'qa'`, см. SPEC.md.

**Поиск + пагинация-селект** (одна строка, `flex gap-3`):
- Input с иконкой `Search` слева, placeholder `Поиск по элементам...`, занимает оставшееся пространство (`flex-1`)
- Select `20 на странице` справа, фиксированная ширина, опции 10/20/50/100

**Фильтр-табы** (`flex gap-2 flex-wrap mt-4`):
Pill-кнопки: `Все` (активна по умолчанию — `bg-gray-900 text-white`), `Продукты`, `Вопросы и ответы`, `Процедуры`, `Контакты`, `Файлы`, `Другое` — неактивные: `bg-white border border-gray-200 text-gray-600 hover:bg-gray-50`. Каждая — `rounded-full px-4 py-1.5 text-sm`.

**Список элементов** (`flex flex-col gap-3 mt-4`):

Каждый элемент — карточка-строка (`border border-gray-200 rounded-lg p-4 hover:border-gray-300`):

```
[бейдж категории, цветной]                          [👁] [✏️] [🗑]
Заголовок элемента (font-medium, text-gray-900)
Описание/ответ, обрезан до 2 строк (text-sm text-gray-500 line-clamp-2)
File: <название источника>  (text-xs text-gray-400, mt-2)
```

Действия справа (`flex gap-1`, иконки 16px, `text-gray-400 hover:text-gray-700`):
- 👁 `Eye` — открыть preview-модалку (полный текст без редактирования)
- ✏️ `Pencil` — открыть форму редактирования (та же модалка, что и "+ Добавить", предзаполненная)
- 🗑 `Trash2` — удаление с подтверждением

**Пустое состояние списка:** если по фильтру/поиску ничего не найдено — центрированный текст "Ничего не найдено" + если поиск пустой — "Добавьте первый элемент базы знаний".

**Пагинация** внизу блока, если элементов больше, чем `на странице`: простые кнопки `←` `1 2 3 ... N` `→`.

## 4. Переиспользуемые компоненты (создать один раз, использовать везде)

Если их ещё нет в проекте — создать в `components/ui/`:

- `<Button variant="primary|outline|ghost|danger" size="sm|md" />`
- `<Badge color="emerald|purple|indigo|amber|gray|slate" />`
- `<Card />` — просто `border border-gray-200 rounded-xl`, с опциональным `padding` пропом
- `<EmptyState icon title description action? />`
- `<ConfirmDialog />` — для всех действий удаления, единый текст-паттерн "Удалить {что}? Это действие необратимо."

Не дублируй разметку кнопок/бейджей внутри каждой страницы — всё через эти компоненты.

## 5. Что НЕ делать

- Не копируй логотип, название "Pleep", футер-юр.тексты конкурента.
- Не добавляй UI подписок/тарифов/пробного периода — этого модуля нет в продукте (SPEC.md раздел 0).
- Не делай превью-карточки агентов как реальный live-рендер чата — это статичный декоративный блок (см. 1.3.1), не трать на это время.
- Не хардкодь цвета мимо токенов из раздела 0 — если нужен новый оттенок, добавь в палитру токенов, а не вставляй произвольный hex прямо в JSX.
